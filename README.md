# SPARCLE_SDR

R workflow for modeling how suitability-constrained agroforestry scenarios affect soil erosion and sediment export across Sub-Saharan Africa using InVEST SDR. The pipeline generates climate-specific suitability masks, condition-aware LULC and biophysical inputs for degraded and non-degraded land, validates scenario transitions, runs standardized SDR comparisons, and synthesizes watershed-scale outputs for manuscript figures.
